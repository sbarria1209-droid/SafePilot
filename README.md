# SafePilot Log Visualizer

Visualización y análisis de registros de tráfico marítimo para Windows.

## Descargar e instalar

**[Descargar la versión más reciente](https://github.com/sbarria1209-droid/SafePilot/releases/latest)**

En la sección **Assets**, descarga el archivo que termina en `_Instalador.exe`.

1. Abre el instalador con doble clic.
2. Pulsa **Instalar** con tu usuario habitual.
3. Abre **SafePilot Log Visualizer** desde el escritorio o el menú Inicio.

Compatible con Windows 10 y 11 de 64 bits. Incluye las dependencias, FFmpeg y el mapa satelital local. No necesitas instalar Python ni descargar la carpeta `_internal` por separado. El instalador ocupa aproximadamente 1,72 GB; reserva unos 2 GB adicionales para la aplicación y espacio para tus registros y cachés.

La instalación se realiza por usuario en `%LOCALAPPDATA%\Programs\SafePilot`, sin solicitar permisos de administrador. Las fotos de buques requieren conexión a Internet cuando todavía no están guardadas en caché.

El instalador no tiene firma digital comercial. Windows SmartScreen o las políticas de una computadora administrada pueden mostrar un aviso o restringir su ejecución.
